# 新旧版XGBRanker整数股评估与回测（2026年10月22日）

本次新版是最新 `XGBRanker_5factor_66train_40external_model_only.zip` 中的150树模型；旧版是此前独立五因子交接包选定的50树模型。两版均为独立XGBRanker，不是三子模型集成。此次同时完成两版回测，不存在“第二模型待接入”。

## 先看哪些文件

- `results/整数股回测报告.md`：可直接用于项目报告章节的分析、口径与限制。
- `results/重点指标_10万10bps.csv`：中文列名，包含两版14窗口、全部策略的核心指标。
- `results/new_vs_old_comparison.csv`：相同窗口、资金、费用、策略的新旧配对值和差值。
- `results/strategy_comparison.csv`：两版全部2,856组情景的原始数值指标，含年化、Sharpe、回撤、波动、胜率、现金和费用。
- `results/charts/ModelComparison/`：同一策略、同一窗口的新旧模型净值对比图，含基准线；全目录230张。`charts/`根目录是新版78张分组图，`charts/Old50/`是旧版78张分组图，总计386张。另有最终期年化对比柱状图。
- `results/prediction_evaluation.csv`：Rank IC、ICIR、NDCG@5等标签排序质量，不与交易盈亏混用。
- `results/Top5_逐笔整数股交易.csv`、`results/Top5_逐周资金.csv`：10万、10bps的完整期两版Top5实例。

## 主情景结果

初始资金100,000，单边10bps（买卖各0.1%），整数股、剩余现金保留；完整210周。

| 版本/基准 | 等权Top5年化 | Sharpe | 最大回撤幅度 |
|---|---:|---:|---:|
| 新版150树 | -6.26% | -0.099 | 55.27% |
| 旧版50树 | 2.82% | 0.237 | 37.69% |
| 共同股票池等权 | 7.70% | 0.485 | 22.43% |

两版最终51周15种主策略均为负年化。新版并非所有策略均更好；例如最终期Top10新版-1.58%、旧版-7.18%，排名加权Top5新版-41.88%、旧版-36.59%。这些历史结果不能证明未来盈利。

## 对比口径

- 同一外部40只股票，8,354个共同日期/股票键，210信号周：2022-08-26至2026-08-28；每周实际可用38–40只。
- 原始外部价格/因子从2015-09-04开始；交付模型在312周训练历史后首个预测日为2022-08-26，因此不把更早训练期补成回测收益。
- 新版加载9个已保存模型，重放排名完全一致，交付四舍五入分数最大差约5.71e-9；旧版按冻结50树参数重跑9次滚动拟合，分数与此前预测逐条完全一致（差0），未重新调参。两版训练与外部股票代码无交集。
- 15种主策略 + 股票池等权、每周清仓Top5两种对照；14窗口；初始资金100,000/10,000；单边0/10/25bps。共2,856组；另216组调仓相位敏感性。
- 所有资金与报价同币种。交付原README出现AUD，但文件没有本次外汇换算，本报告不声称其为AUD计价投资回报。
- 排序质量使用target1下一周收盘到收盘对数收益标签；组合盈亏使用交付buy_price/sell_price开盘/收盘代理和实际股数。
- 目标股数=floor(目标权重×开盘资产/[买价×(1+买入费率)])。先卖后买，按排名顺序买入，现金不足继续向下截断，剩余现金不重新分配，不透支。
- 每个窗口独立从现金开始。主策略跨周连续持股，2/4周策略非调仓周保持股数；窗口末全卖并计费。原脚本周末清仓规则是单独对照。
- 年化=(期末/期初)^(52/周数)-1；Sharpe=周收益均值/样本标准差×sqrt(52)，无风险利率0；回撤包含初始资金。年化与Sharpe并非同一统计量。
- 过去亏损过滤、历史波动、趋势只取当时可知的前序收盘代理。正预测分数并非正预期收益；不根据未来亏损剔除股票。
- 最终期固定2025-09-05至2026-08-21，共51周；已查看历史结果，不能再称新的未见测试。重叠窗口不是独立重复样本。

## 复现

验证环境：macOS，Python 3.13.3，numpy 2.5.3，pandas 3.0.6，xgboost 3.4.1；R 4.5.2（基础图形Quartz，不依赖额外R包）。安装Python依赖后在本文件所在目录运行：

```bash
python3 -m pip install -r requirements.txt
python3 run_all.py
```

只复现交易结果可直接运行 `python3 integer_backtest.py`，再运行 `python3 verify_integer.py` 和 `python3 evaluate_comparison.py`。各脚本以自身目录为根，不依赖原电脑绝对路径。预测复现、回测、图表、报告按顺序执行；不对40只外部股票重新选参。R绘图采用macOS Quartz，其他操作系统需选择其可用图形设备。

代码职责：`prepare_comparison.py`重放新权重并对齐旧预测；`replay_old50.py`核对旧模型重训复现；`integer_backtest.py`逐股整数交易引擎；`verify_integer.py`独立重建现金、持仓、指标并与交付模拟对照；`evaluate_comparison.py`计算配对差及标签评估；`plot_results.R`输出PNG；`build_report.py`生成报告与SQLite来源；`sync_report_app.py`同步交互报告数据并保留报告ID。

原始模型/脚本在`source/`，旧版源码、训练输入与冻结结果在`old_source/`，共同回测输入在`inputs/`；`prepared/`包含实际预测和版本核对记录。`results/weekly_nav.csv.gz`是全部成本与资金情景的周资金路径；完整交易和持仓压缩CSV覆盖10bps两资金情景。其他费用可用引擎的`detail=True`单独重跑流水。`phase_sensitivity.csv`含相位结果。`run_manifest.json`和`verification.json`说明运行参数和核验范围。

## 核验和限制

通过2,856组指标复算、464,859笔交易及536,888条持仓核查，并按订单重建全部10bps资金；通过12组交付脚本清仓模拟参考对照。股数均为整数，现金不透支，最大金额算术误差约1.89e-9。另确认2,000预算、300股价只能买6股的边界例子，以及2周持仓跨周跳空、首次损失回撤等。

结果是基于交付开收盘代理的历史模拟；未独立核验公司行动、复权、分红、真实成交和因子披露时点，不含滑点、冲击及容量影响。完整说明在报告中。模型排序质量与交易收益应分别解读。
