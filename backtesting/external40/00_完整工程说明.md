## 环境与运行

原核验环境：macOS、Python 3.13.3、numpy 2.5.3、pandas 3.0.6、xgboost 3.4.1；绘图另需R 4.5.2。Python精确版本见requirements.txt。

在本文件所在目录运行：

```bash
python3 -m pip install -r requirements.txt
python3 check_package.py
python3 run_all.py
```

run_all.py会先复现独立新旧两版，再复现集成及三个子模型，生成数值、图表与Markdown；有些步骤会重算并覆盖同名输出，建议在解压副本内运行。完整复现耗时明显长于文件检查。集成任务在输入与引擎指纹一致时会复用已有回测结果，核验脚本也会复用已有通过记录，不代表每次命令都会从头重算。

仅重放已保存的45个集成子模型并核对预测，然后运行集成部分：

```bash
python3 ensemble_extension/complete_ensemble.py
python3 ensemble_extension/verify_extension.py
python3 ensemble_extension/evaluate_extension.py
Rscript ensemble_extension/plot_extension.R ensemble_extension
python3 ensemble_extension/extend_report.py
```

本包保留了上述集成流程所需的独立两版prepared和results输入，不需要先重新训练独立模型。

R绘图脚本当前使用macOS Quartz设备；Windows/Linux需调整PNG设备。交互报告源码在report_app，重新编译该前端需原Data插件环境；Python计算、CSV、Markdown及R图表不依赖Data插件。已有静态输出保留。部署和打包辅助脚本不是数值复现入口。
