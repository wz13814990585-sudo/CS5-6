# 新 40 只股票：预测排名与机器学习评估

本目录是一套独立的排名预测评估输出。复用第二版已完成的逐周样本外预测，原 66 只股票用于训练，新 40 只用于测试。超参数、模型权重、训练窗口和模型更新频率均保持原配置，不重新训练。

运行结果位于 `outputs/current/`。先打开该目录下的 `metrics/overall_metrics.csv` 或 `metrics/stage_metrics.csv` 查看模型表现，逐股结果位于 `predictions/stock_rankings.csv`。

## 已完成结果摘要

| 模型 | 全时期 Rank IC | 全时期 NDCG@10 | Final Test Rank IC | Final Test NDCG@10 |
|---|---:|---:|---:|---:|
| Model 1 | 0.024332 | 0.392024 | 0.032484 | 0.374785 |
| Model 2 | 0.003108 | 0.393572 | -0.006578 | 0.351152 |
| Model 3 | 0.016570 | 0.394401 | 0.053990 | 0.377742 |
| Ensemble | 0.014367 | 0.394680 | 0.033967 | 0.380078 |

随机排序的 NDCG@10 基准为全时期 0.379301、Final Test 0.372466。NDCG 不是分类准确率，应结合随机期望和时间稳定性解释。集成模型全时期平均 Rank IC 的 95% 区块 bootstrap 区间约为 [-0.003682, 0.032873]，Final Test 约为 [-0.017796, 0.089654]；两者均包含 0，不能仅凭均值为正断言稳定的正向预测能力。

本版本生成 15 个 CSV。7 项逻辑测试通过；独立重算 1,464 行周指标，核对 128 行汇总，最大数值差约 7.8e-16。所有预测分数和原结果一致，已有源文件哈希保持不变。数据检查还列出 22 个末端数值超过一年未变化的股票因子组合，供追溯来源。

## 评估对象

预测问题是“下一周哪些股票相对表现更好”。模型输出为排序分数，真实下一周对数收益只用作评价标签。分数不代表收益率、股价或上涨概率。

保留 Model 1（五因子、156 周窗口）、Model 2（两因子、52 周窗口）、Model 3（五因子正则化、52 周窗口）及三个模型百分位分数的等权集成。每 26 周重训、每周预测。新股票标签不进入训练。

## 指标定义

所有汇总先逐周计算，再对周等权平均，不把所有股票周混在一起计算一个相关系数。随机基准按每周实际股票数计算。指标越高越好，除排名误差类越低越好；并列比例只描述分辨率。

| 指标 | 含义与计算口径 |
|---|---|
| IC | 分数与真实下一周对数收益的 Pearson 相关系数 |
| Rank_IC | Spearman 排名相关系数，平均排名处理并列 |
| ICIR / Rank_ICIR | 相应周序列均值除以样本标准差（ddof=1），不年化 |
| Positive_IC_Ratio / Positive_Rank_IC_Ratio | 有效周中相关系数大于 0 的比例 |
| Weekly_IC_Std / Weekly_Rank_IC_Std | 周相关系数的样本标准差 |
| Median_Rank_IC | 周 Rank IC 中位数 |
| Kendall_Tau | Kendall tau-b，考虑并列的整体排序一致性 |
| Pairwise_Accuracy | 对真实收益不相等的股票对，预测顺序正确计 1、预测同分计 0.5、顺序错误计 0 |
| Random_Pairwise_Accuracy | 随机排序期望为 0.5 |
| NDCG_at_5 / 10 / all | 前 5、前 10、全部股票的归一化折损累计增益 |
| Random_NDCG_at_5 / 10 / all | 当前周真实等级在均匀随机排序下的 NDCG 精确期望 |
| Hit_Rate_at_5 / 10 | 预测前 K 名与真实前 K 名的交集数量除以 K；本定义中 Precision@K 与 Recall@K 相同，不重复列出 |
| Random_Hit_Rate_at_5 / 10 | 当周随机排序期望 K/N |
| NDCG / Hit_Rate 的 Above_Random 列 | 模型指标减对应随机期望，不表示显著性检验 |
| Rank_MAE | 预测平均排名与真实平均排名的绝对差均值，单位为名次 |
| Rank_RMSE | 排名误差平方均值的平方根，单位为名次；不是收益率回归误差 |
| Normalized_Rank_MAE | 每周 Rank_MAE/(当周股票数−1)，便于比较不同规模股票池 |
| Random_Normalized_Rank_MAE | 随机打乱本周预测分数与股票的对应关系后，归一化排名误差的精确期望，保留预测并列结构 |
| Score_Tie_Pair_Ratio | 同分股票对占全部股票对的比例 |
| Rank_IC_CI95_Lower / Upper | 周均 Rank IC 的 95% 循环移动区块 bootstrap 百分位区间，4 周区块、4,000 次、种子 5703 |

NDCG 的真实等级沿用训练标签定义：每周按连续真实收益升序取平均排名，`relevance = floor((rank−1)*5/N)`，截断到 0–4；增益为 `2^relevance−1`，位置折扣为 `1/log2(position+1)`。NDCG 对预测同分取平均期望。该等级只是评估排序的相关性等级，不是涨跌类别。

用于展示的整数排名及前 K 名集合按分数降序、ticker 升序确定；股票真实收益并列时也按 ticker 确定整数名次。相关系数和排名误差使用平均名次。NDCG 和命中率采用不同的并列处理，已明确标注，不应当作同一指标。

置信区间只对至少 8 个完整有效周计算，较短区间留空。4 周区块是固定的评估约定，不代表覆盖所有可能的时间依赖；区间不是交易阈值，也不校正多模型比较的选择偏差。原参数曾参考原股票池历史，本次衡量其在新股票池的泛化。

模型未输出具体收益率或类别概率，因此不计算收益率 RMSE/MAE、收益率 R²、分类 Accuracy/F1 或概率 AUC。上述 Rank_RMSE/Rank_MAE 仅评估排名。

## 数据解释

真实标签定义由用户确认，因缺少价格，无法独立重建新股票的收益标签。因子发布时点未独立核验。`factor_quality.csv` 中长期不变的值仅标为需要核查，不能直接认定错误；`last_observed_change_date` 是输入数值最后变化的观测日期，不是财报发布日期。RH 的营收增长与债务资产比等记录应追溯上游来源，本版本保持原输入。
